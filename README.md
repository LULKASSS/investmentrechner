# Investmentrechner

Wie groß wird die Rentenlücke, was kostet es, sie zu schließen, und in welche Töpfe gehört das Geld? Fünf Fragen, dann eine Geschichte in vier Schritten (Daten, Lücke, Weg, Lösung) und ein Vorschlag als PDF.

**Öffnen:** https://lulkasss.github.io/investmentrechner/

Modellrechnung mit Werten 2026, keine Zusage und keine Anlageberatung.

**Versuch: Ziele-Planer** (`ziele.html`) – Notgroschen, Auto, Wohnung, Rente und mehr: was jedes Ziel im Monat kostet, wann es eng wird und wie alles ins Budget passt.

## Mac-App

```bash
npm install
npm run app:install
```

Baut `Investmentrechner.app` und legt sie in den Programme-Ordner. Gleiche Oberfläche wie die Webseite, läuft ohne Browser.

## Entwicklung

- `npm run dev` – lokal unter http://localhost:5180
- `npm test` – Fehlercheck und automatische Tests (Browser, iPhone-Größe, Mac-App)
